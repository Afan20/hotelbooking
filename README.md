# hotelbooking

Hotel booking application with:

- `frontend/` React + Vite staff console
- `backend/` Express + Prisma API

## Agent data MVP

The backend includes an agent-ready data layer for SMS/WhatsApp automation:

- Amenities and policy knowledge tables
- Bot message templates
- Conversation and message logging
- Review request tracking
